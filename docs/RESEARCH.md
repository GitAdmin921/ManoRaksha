# Phase 1 — Research Plan

## Questions

- What problems prevent a distressed person from using a conventional app?
- When is voice easier than touch/UI navigation?
- When is video helpful or harmful?
- What communication patterns are safe?
- What should trigger human escalation?
- What data is actually necessary?
- How should consent work when the user is distressed?

## Research outputs

- Problem statement
- User personas/journeys
- Accessibility requirements
- Safety requirements
- Privacy/data map
- MVP acceptance criteria
