# MANORAKSHA — Compassionate Shield

Starter architecture for the MANORAKSHA research prototype.

## Structure
- frontend/ — React/TypeScript UI placeholder
- backend/ — FastAPI service placeholder
- ml/ — baseline/risk/fusion research modules
- edge/ — consent and local-processing modules
- database/ — schema/migrations
- docs/ — architecture, privacy and research notes

This is a scaffold, not a clinical product. AI risk estimates must not be treated as diagnoses.
